# Research Git Protocol

## Task Tracking & Documentation

- **Research Logs:** After completing a deep-dive search or scraping task,
  you are authorized to commit a summary of your findings to the
  research/logs/ directory in the repository.
- **Format:** Use the local GitLab MCP server to create or update files.
  Ensure commit messages are descriptive (e.g., "Research: Tyler Childers
  2026 Tour Dates Update").
